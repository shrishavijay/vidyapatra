# VidyaPatra

A free, searchable database of previous-year question papers for Indian students preparing for board exams.

## Live Site
https://shrisha.pythonanywhere.com

## The Problem

Every year, millions of Indian students preparing for board exams struggle to find previous-year papers from their colleges for practice. These papers are often not available to students, as they're scattered across the internet and not properly stored by colleges.

## The Solution

VidyaPatra lets any student search a database of question papers by subject, stream, or exam year — instantly, for free.

## Features

- Live search by subject, college, or year
- Filter by stream (Science, Commerce, Arts, Engineering)
- Clean, mobile-responsive interface
- Direct links to view papers

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (vanilla, no frameworks)
- **Backend:** Python, Flask
- **Database:** SQLite with Flask-SQLAlchemy
- **Deployment:** PythonAnywhere

## How to Run Locally

1. Clone this repository
git clone https://github.com/shrishavijay/vidyapatra.git
cd vidyapatra

2. Install dependencies
pip install flask flask-sqlalchemy

3. Run the app
python app.py
